# 방향 점검: 강의자료(Day02·Day03) vs 현재 작업

## 결론
- 주제 선정과 중간 주제 발표는 강사님 요구 사항이고, 현재 방향(청년정책·의료관광)도 강사님 의견을 받은 상태 → **방향은 유지**
- 새 파일은 만들지 않고, **강의 산출물 형식을 우리 주제에 맞춰 기존 md 파일을 고치는 것**이 남은 일

## 1. 강의 산출물 → 우리 주제로 옮기기

| 강의 산출물 | 강의 기준 | 우리 주제에서의 의미 |
|---|---|---|
| 지역 자산 노트 | 자산 1개 = 노트 1개, 6유형 분류 [Day03 p6] | 청년센터·청년 공간(커뮤니티), 대구 의료기관·메디시티(산업) |
| 데이터 소스 노트 | 어떤 데이터가 어디에 있는지 [Day02 p41] | 온통청년 OpenAPI, 젊프 센터 목록, 심평원 비급여 API, KHIDI 유치실적 보고서 |
| 데이터셋 명세 | 출처·열 정의·행 단위·범위·품질·활용 가설 [Day03 p22] | 위 데이터들의 명세 (기존 노트 안에 항목으로 추가) |
| 교차검증 | 독립 출처 2개 이상 [Day03 p13] | 외국인 환자 수(KHIDI + 복지부)처럼 핵심 주장마다 표기 |
| 페르소나 | 브랜드 페르소나 [Day02 p5] | 서비스의 톤·핵심 메시지 + 사용자(청년 / 외국인 환자) |

## 2. 기존 파일별 고칠 점

| 파일 | 고칠 점 |
|---|---|
| CLAUDE.md | 6주 목표를 우리 주제 기준으로 구체화 (예: 청년·외국인 환자 페르소나 md) |
| research/청년정책/*.md, research/의료관광/*.md | 출처 표에 **기준 시점** 열 추가, 핵심 수치에 교차검증 표시, 데이터 항목에 **열 정의·행 단위·갱신일·품질 메모** 추가 |
| subject/subject.md | 강의 일정(11/2 인벤토리 → 11/3 페르소나 → 11/4 스토리보드)에 맞춘 다음 단계로 갱신 |
| subject/research-plan.md | 팀원 이름 정리, 최종 3개 아이디어 기준으로 갱신 |
| research/research.md | 우리 주제와 관련 없는 키워드 비중이 큼 → 관련 키워드 위주로 정리하거나 그대로 참고용 유지 |

## 3. 그대로 써도 되는 것
- 파일로 저장, 출처 URL, 원자료 확인, "미확인" 표기 — 강의 규칙과 같음 [Day02 p26, Day03 p13]
- 출처 등급(공식/통계/언론/개인) — Day03 등급표와 같음
