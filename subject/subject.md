# 주제 선정 (데이터 2팀 중간 발표 기준)

> 대구에 흩어진 공공 정보를 모아, 필요한 사람에게 바로 연결하는 서비스

## 선택한 아이디어 3개

| # | 아이디어 | 한 줄 설명 | 분야 |
|---|---|---|---|
| 1 | 대구 청년 정책 원스톱 플랫폼 | 내 조건이나 고민을 입력하면 맞는 청년 정책을 찾아 공식 신청 페이지로 연결 | A |
| 2 | 메디시티 병원 신뢰·가격 비교 | 외국인 환자에게 공식 인증 배지와 적정 가격 정보를 다국어로 제공 | B |
| 3 | 구·군별 청년 공간 & 정책 비교 | 9개 구·군의 청년 공간과 혜택을 한눈에 비교하고 바로 예약·신청 | A |

## 분야 묶음

### 분야 A · 대구 청년 정책·공간 (아이디어 1, 3)
- 공통 문제: 정책·공간 정보가 시청, 청년센터, 구청에 흩어져 있어 청년들이 혜택을 놓침

### 분야 B · 외국인 의료관광 (아이디어 2)
- 핵심 문제: 외국인 환자는 믿을 만한 병원인지, 가격이 적정한지 판단할 정보가 없고, 있어도 한국어뿐

### 두 분야의 공통 뼈대
흩어진 공공데이터 통합 → AI 상황형 검색·추천 → 공식 페이지로 바로 연결

## 분야별 조사 계획

| 조사 항목 | 분야 A · 청년 정책·공간 | 분야 B · 외국인 의료관광 |
|---|---|---|
| 데이터 확보 | 온통청년 OpenAPI의 대구 정책 범위·갱신 주기, 9개 구·군 청년 공간 목록 | 심평원 비급여 API에 의원급(피부·성형) 포함 여부, 유치기관·인증·전문병원 데이터 |
| 기존 서비스 | 온통청년, 대구청년센터 사이트와 무엇이 다른지 | 메디컬코리아 등 기존 외국인 환자 안내 서비스와 무엇이 다른지 |
| 사용자 수요 | 대구 청년 대상 간단 설문·인터뷰 | 외국인 환자 통계와 후기 (2025년 대구 외국인 환자 19,243명, 전년 대비 +31.4% — 한국보건산업진흥원 보고서 원문 표 2.13·3.73에서 확인. 상세: research/의료관광/메디시티-병원-신뢰-가격-비교.md) |
| 기술 검증 | 자연어 고민 → 정책 매칭 AI 추천 | 기관별 병원명 매칭(주소·요양기호), 다국어 처리 |

### 3인 역할 분담

| 담당 | 맡을 일 | 확인할 것 | 완료 기준 |
|---|---|---|---|
| **팀원 1 · 병원 기본·시간·지도 데이터** | 공공데이터포털 API 키 발급 후 심평원 병원정보서비스·상세정보서비스 호출 | ① 대구 병원 목록과 좌표가 위도·경도인지 ② 진료시간·휴진 항목이 채워진 병원 비율 ③ 메디컬코리아 등록 병원 145곳과 병원명·주소 매칭률 ④ API에 없어서 크롤링이 필요한 항목 목록 (임시 휴진 등) | 대구 병원 샘플 CSV + 채움 비율 표 |
| **팀원 2 · 가격 데이터·규제** | 심평원 비급여 API 호출, 크롤링 범위 결정 | ① 의원급 피부·성형 항목(보톡스·필러·레이저 등) 포함 여부 ② 대구 병원 중 가격이 있는 병원 수 ③ 병원 가격 노출 시 의료광고 규제 범위 ④ Aside 기능과 대상 사이트 약관·robots.txt | 대구 시술 가격 샘플 CSV + 규제·크롤링 가능 여부 메모 |
| **팀원 3 · 다국어·챗봇·유입** | 언어·모델 테스트, 수요 근거 보강 | ① 지원 언어 6개 확정과 브라우저 언어 자동 선택 방식 ② 저렴한 모델로 6개 언어 테스트 질문 세트 실행 (숫자는 데이터에서만 답하는지) ③ 한국관광공사 대구공항 입국객 분석 원문 · 데이터랩 대구 필터 ④ "오기 전" 유입 장치 (노선 도시·메디웰니스 상품 연계) | 언어별 테스트 결과 표 + 유입 근거 출처 목록 |

- 공통 규칙: 결과는 research/의료관광/ 아래 노트로 저장, 숫자는 출처(등급·기준 시점) 필수, 못 찾은 것은 "미확인"
- 의존 관계: 팀원 1의 병원 목록(ykiho)을 팀원 2가 가격 조회에 사용 → 팀원 1이 대구 병원 목록부터 먼저 공유

### 데이터 채우기 원칙
1. **API 먼저 테스트** — API로 받을 수 있는 항목은 직접 수집하지 않음
2. **빈칸 목록 확정** — 테스트 후 "API에 없거나 비어 있는 항목"만 표로 정리
3. **직접 채우기는 범위를 좁혀서** — 예: 중구·수성구 피부과·성형외과 상위 병원부터 (전체 병원 아님)
4. **직접 채운 값은 칸마다 출처 URL·확인일 기록**, API 값과 구분하는 열(source: api / manual) 추가
5. 직접 채울 가능성이 높은 항목(추정): 임시 휴진, 이벤트·패키지 가격, 외국어 상담 가능 여부, 번체·태국어·베트남어 번역

## 부록: 브레인스토밍 후보 아이디어

### 생활·관광
- **공공 화장실 찾기**: 주변 공공 화장실 위치 안내
- **맛집 추천**: 카테고리별 맛집 + 이용자 유형별(직장인·국내 관광객·외국인이 자주 가는 곳) 추천
- **야구**: 야구장, 굿즈 판매처, 야구장 주변 식당 추천
- **관광·축제**: 시즌별 축제 정보와 대구 대표 음식(막창, 뭉티기 등) 추천
- **생활 민원 신고**: 도로·공공시설 파손, 쓰레기 무단 투기를 사진·위치로 공유하고 담당 기관 처리까지 확인 (미국 SeeClickFix 참고)

### 무더위쉼터
- **"진짜 들어갈 수 있는 쉼터"**: 지금 이 시간에 이용 가능한 쉼터만 표시 (경로당 제외 필터, 운영시간, 주말·야간 운영, 수용 인원)
- 대상: 배달 라이더, 야외 노동자, 관광객, 청년
- 폭염특보 시 가장 가까운 열린 쉼터 알림
- 데이터: 행정안전부 무더위쉼터 표준데이터, 기상청 폭염특보 API
- 한계: 여름 한철 서비스

### 외국인 의료관광 → 선택 아이디어 2
- **대구판 '강남언니'(외국인 특화)**: 진료 분야별 병원 검색, 공개 가격 비교, 외국어 지원 확인, AI 다국어 상담·예약 보조
- **AI 의료관광 코디네이터**: 희망 진료·체류 기간·예산에 맞춘 일정, 진료 전 준비사항 안내
- **메디컬 트래블 패스**: 병원·공항·숙소 이동 정보와 주변 관광 동선 통합
- **공식 데이터 기반 신뢰·가격 비교**: 유치기관 등록·전문의 수·인증 여부·비급여 진료비를 다국어로 제공
- 핵심 차별점: 광고가 아닌 비교 가능한 데이터 중심, 의료 이용 여정 전체 지원, 의료·관광·교통 정보 연결

### 청년 일자리·정책 → 선택 아이디어 1, 3
- **청년 일자리 내비게이터**: 전공·경력·희망 연봉·출퇴근 지역 기반 대구 채용공고 추천, 부족 역량과 관련 교육 안내
- **청년 취업지원금·정책 추천 AI**: 나이·거주지·취업 상태·소득 조건으로 신청 가능한 지원제도 추천, 마감일 알림
- **청년 정책 원스톱 플랫폼**: 프로필 조건 필터링 + 자연어 고민 입력 시 AI 정책 추천 + 공식 신청 페이지 아웃링크
  - 데이터 투트랙: 상설 사업(희망옷장 등)은 자체 DB, 수시 모집 사업은 온통청년 OpenAPI 연동
- **구·군별 청년 공간·정책 비교**: 청년센터 이용 저조 문제 해결을 위해 구·군별 청년 공간과 혜택을 통합 비교·탐색
