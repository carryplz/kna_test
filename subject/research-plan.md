## 1단계: 같은 기준으로 걸러내기

### 평가 기준

| 기준 | 확인할 질문 | 조사할 곳 | 가중치 |
|---|---|---|---|
| ① 데이터 확보 | 쓸 수 있는 공공데이터나 API가 있나? 크롤링에 약관·법적 문제는 없나? | 공공데이터포털(data.go.kr), 대구시 열린데이터, 각 기관 Open API | ×2 |
| ② 문제의 근거 | 이 문제가 실제로 있다는 통계, 기사, 민원이 있나? | 대구시 보도자료, 지역 언론, 통계청(KOSIS), 국민신문고 | ×1 |
| ③ 기존 서비스 | 이미 같은 서비스가 있나? 있다면 우리가 무엇을 다르게 할 수 있나? | 앱스토어, 정부·지자체 앱, 웹 검색 | ×2 |
| ④ AI가 꼭 필요한가 | 일반 검색이나 필터로도 충분하지 않은가? LLM이어야 하는 이유가 분명한가? | 팀 내부 토론 | ×1.5 |
| ⑤ 기간 안에 만들 수 있나 | 프로젝트 기간 안에 데모가 나올까? 규제 리스크는 없나? | 관련 법령, 개발 범위 추정 | ×1 |

> 데이터가 없으면 만들 수 없고, 같은 서비스가 이미 있으면 발표에서 가장 먼저 지적받습니다. 그래서 ①과 ③에 가중치를 더 줬습니다. 가중치는 팀에서 조정하세요.

| 점수 | ① 데이터 | ② 근거 | ③ 기존 서비스 대비 | ④ AI 필요성 | ⑤ 실현 가능성 |

### 그룹별로 먼저 확인할 것

**A. 생활 편의·안전**
- [ ] 공중화장실, 무더위쉼터 표준데이터가 공공데이터포털에 있는지, 언제 갱신됐는지
- [ ] 지도 앱 검색과 비교했을 때 AI가 더해 주는 가치가 있는지(약점이 될 가능성 큼)
- [ ] 시민 불편 신고: **안전신문고, 국민신문고**와 무엇이 다른지
- [ ] 시민 불편 신고: 대구시 민원 처리 체계와 연계할 수 있는지

**B. 관광·음식**
- [ ] 한국관광공사 TourAPI, 대구시 축제 정보 API에서 얻을 수 있는 항목
- [ ] 맛집 데이터를 어디서 구할지(네이버·카카오 리뷰 크롤링은 약관 위반 위험)
- [ ] 현지인·관광객·외국인을 구분할 수 있는 데이터가 있는지(카드 소비 데이터, 관광 데이터랩 등)
- [ ] 야구: 구단 공식 앱이나 기존 서비스와 겹치는 부분, 시즌에 따라 이용자가 몰리는 정도

**C. 의료관광**
- [ ] 한국보건산업진흥원 외국인환자 유치 통계에서 대구 실적, 국적별·진료과별 비중
- [ ] 건강보험심사평가원 병원정보, 비급여 진료비 공개 데이터의 범위
- [ ] 외국인환자 유치기관 등록 현황(대구)
- [ ] 경쟁 서비스 분석: 강남언니, 메디시티대구 포털 등
- [ ] **규제**: 의료광고 규제, 환자 유치·알선 규정, 가격 비교와 예약 중개가 허용되는 범위

**D. 청년**
- [ ] 고용24(워크넷) 채용정보 API, 온통청년 청년정책 API를 쓸 수 있는 범위
- [ ] 대구시 청년센터와 대구시 자체 청년정책 데이터
- [ ] 경쟁 서비스 분석: 온통청년, 각 지자체의 정책 추천 서비스
- [ ] 대구에 특화된 점과 개인 맞춤형인 점을 무엇으로 보여줄지

## 진행 방식

1. **역할 나누기**: 그룹마다 담당자 1명. 제안자가 아닌 사람이 맡으면 더 객관적으로 볼 수 있습니다.
2. **1단계 조사**: 담당자가 위 체크리스트를 확인하고 평가표와 근거 기록을 채웁니다.
3. **선별 회의(30분)**: 점수표를 근거로 2~3개를 고릅니다.
4. **2단계 조사**: 고른 주제마다 위 6개 항목을 정리합니다.
5. **확정 회의**: 2단계 결과를 비교해 최종 주제 하나를 정합니다.
