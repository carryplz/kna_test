# 조사 방법 · 병원 기본정보 + 진료시간·휴무 (팀원 1 담당)

## 목표
대구 병원에 대해 **API로 받을 수 있는 것**과 **비어 있어서 직접 채워야 하는 것**을 숫자로 가려내기.

## 0. 준비 (1회)
1. 공공데이터포털(data.go.kr) 로그인 → 아래 두 API **활용신청** (개발계정 자동승인, 일 10,000건)
   - 건강보험심사평가원_병원정보서비스 (15001698) — 병원 목록·좌표
   - 건강보험심사평가원_의료기관별상세정보서비스 (15001699) — 진료시간·휴진·진료과목
2. 마이페이지에서 **일반 인증키** 확인
3. 키는 `.env` 파일에만 저장하고 `.gitignore`에 `.env` 추가 — **공개 저장소에 키를 올리지 않기**
4. 대구 시도코드·진료과목코드는 보건의료빅데이터개방시스템(opendata.hira.or.kr) > 코드조회에서 확인 (추측해서 넣지 않기)

## 1. 대구 병원 목록 받기 — 병원정보서비스 `getHospBasisList`
- 조건: 대구 시도코드, 페이지 단위로 전부 받기
- 저장: 원본 응답은 `research/data/raw/`, 정리본은 `research/data/daegu_hospitals.csv`
- 확인할 것
  - 전체 병원 수, 종별(의원·병원·종합병원 등) 분포
  - 피부과·성형외과 병원 수 (진료과목 기준)
  - **좌표(XPos·YPos)가 위도·경도인지**: 병원 3곳을 지도에서 주소와 비교

## 2. 진료시간·휴무 받기 — 상세정보서비스 `getDtlInfo2.8`
- 전체를 한 번에 하지 말고 **샘플부터**: 중구·수성구 피부과·성형외과
- 병원마다 1번에서 받은 ykiho로 호출
- 확인할 항목과 **채움 비율** (값이 있는 병원 수 / 샘플 수)

| 항목 | 필드 |
|---|---|
| 평일 진료시간 | trmtMonStart ~ trmtFriEnd |
| 토·일 진료시간 | trmtSatStart·End, trmtSunStart·End |
| 점심시간 | lunchWeek, lunchSat |
| 접수시간 | rcvWeek, rcvSat |
| 휴진 안내 | noTrmtSun, noTrmtHoli |

- 같이 받으면 좋은 것: `getDgsbjtInfo2.8`(진료과목·의사 수)

## 3. 정확도 검증 (5곳)
- API 진료시간을 병원 공식 홈페이지와 비교 → 일치 / 불일치 / 홈페이지에 정보 없음
- 지도 앱·블로그는 참고만 (출처 등급 낮음)

## 4. 메디컬코리아 CSV와 매칭
- 메디컬코리아 대구 등록 병원 145곳은 **영문 이름·영문 주소**라 이름 매칭이 어려움
- **전화번호로 매칭** 먼저 시도 (메디컬코리아 전화번호 열 ↔ 심평원 telno), 안 되면 주소
- 결과: 매칭률 (매칭된 병원 수 / 145)

## 5. 산출물
- `research/data/daegu_hospitals.csv` — 병원 목록 + 진료시간 (source 열: api)
- 노트 1개 — 아래 표 포함
  - 채움 비율 표 (항목별)
  - 좌표 형식 확인 결과
  - 정확도 검증 5곳 결과
  - 메디컬코리아 매칭률
  - **빈칸 목록** (API에 없거나 비어서 직접 채울 항목) → 팀원 2·3에게 공유
- 팀원 2에게 먼저 공유: 대구 피부과·성형외과 **ykiho 목록** (가격 조회용)

## Claude Code 요청 예시
```
.env의 인증키로 심평원 병원정보서비스 getHospBasisList를 호출해서
대구 병원 전체를 받아 줘. 원본은 research/data/raw/에, 정리본은
research/data/daegu_hospitals.csv에 저장하고 종별·진료과목별 병원 수를 표로 보여 줘.
인증키는 화면이나 파일에 출력하지 마.
```
```

항목별 채움 비율을 표로 만들어 줘.
```
