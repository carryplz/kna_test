# 아이디어 1 · 대구 청년 정책 원스톱 플랫폼

## 1. 한 줄 요약
청년정책 데이터는 온통청년 OpenAPI(지역코드 조회 가능)로 확보할 수 있고, 대구 특화 상설 사업(희망옷장 등)은 대구시·청년센터 사이트에 흩어져 있어 "통합 + 자연어 추천 + 공식 신청 연결"의 차별화 여지가 있음.

## 4. 콘텐츠·서비스 관점에서 눈에 띄는 점
1. **데이터는 이미 열려 있음** — 온통청년 OpenAPI가 법정시군구코드 조회를 지원해 대구 정책만 필터링 가능 [2]. 수집 자체보다 "정리·추천" 품질이 차별점이 됨.
2. **상설 사업은 API 밖에 있음** — 희망옷장처럼 연중 운영되는 대구 사업은 별도 사이트로 운영되어 [4][5], 발표 자료의 "자체 DB(상설) + API(수시)" 투트랙 설계와 맞아떨어짐.
3. **기존 서비스는 '검색' 중심** — 온통청년은 통합검색·챗봇 상담을 이미 제공 [1]. 따라서 "자연어 고민 → 정책 매칭"이 기존 챗봇과 어떻게 다른지 명확히 해야 함.
